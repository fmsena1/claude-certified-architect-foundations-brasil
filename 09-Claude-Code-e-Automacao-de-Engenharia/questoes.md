# Revisão Guiada - Claude Code e Automação de Engenharia

## Quick Review (Q&A)

- **Pergunta rápida:** O que Claude Code adiciona em relação a uma conversa comum com Claude?
  **Resposta curta:** Acesso a um ambiente real de desenvolvimento e um loop de ação sobre arquivos, terminal e Git.
- **Pergunta rápida:** Quais os três níveis de permissão de ferramentas?
  **Resposta curta:** Permitir, perguntar (confirmar) e negar.
- **Pergunta rápida:** Por que hooks são mais confiáveis que instruções de prompt para regras críticas?
  **Resposta curta:** Porque rodam de forma garantida no ambiente de execução, sem depender do modelo lembrar.
- **Pergunta rápida:** Quando vale a pena empacotar uma instrução numa skill?
  **Resposta curta:** Quando a tarefa é repetitiva, segue um padrão, mas ainda exige alguma decisão contextual.
- **Pergunta rápida:** Um commit gerado pelo agente dispensa revisão humana?
  **Resposta curta:** Não. Deve ser revisado como qualquer outra mudança de código.
