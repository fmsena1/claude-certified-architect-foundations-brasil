# Revisão Guiada - Deploy Enterprise

## Quick Review (Q&A)

- **Pergunta rápida:** Quais são os quatro canais de acesso ao Claude cobertos neste módulo?
  **Resposta curta:** API direta, Amazon Bedrock, Google Vertex AI e Microsoft Foundry.
- **Pergunta rápida:** Qual é o critério principal para escolher entre eles?
  **Resposta curta:** A fronteira de compliance e procurement de nuvem que a organização já tem estabelecida.
- **Pergunta rápida:** Todo recurso novo do Claude está disponível em todos os canais ao mesmo tempo?
  **Resposta curta:** Não. É preciso confirmar disponibilidade por canal antes de arquitetar.
- **Pergunta rápida:** Quem opera preço e SLA num canal de nuvem parceira?
  **Resposta curta:** O provedor de nuvem parceiro (AWS, Google Cloud ou Microsoft), não a Anthropic diretamente.
- **Pergunta rápida:** O que a organização herda ao usar um canal de nuvem parceira?
  **Resposta curta:** A fronteira de residência de dados, auditoria e controle de identidade que já usa naquela nuvem.
