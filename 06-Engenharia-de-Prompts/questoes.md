# Revisão Guiada - Engenharia de Prompts

## Quick Review (Q&A)

- **Pergunta rápida:** Por que um prompt ambíguo produz respostas inconsistentes?
  **Resposta curta:** Porque deixa espaço para o modelo inferir o que não foi dito.
- **Pergunta rápida:** Para que servem as XML tags num prompt?
  **Resposta curta:** Para separar instrução, contexto e dado de entrada sem ambiguidade.
- **Pergunta rápida:** O que é few-shot prompting?
  **Resposta curta:** Incluir exemplos de entrada e saída para mostrar o padrão esperado.
- **Pergunta rápida:** Quando chain-of-thought costuma compensar o custo?
  **Resposta curta:** Em tarefas com múltiplos passos de raciocínio ou decisão.
- **Pergunta rápida:** O que falta a um prompt que só descreve o caminho feliz?
  **Resposta curta:** Regras explícitas para exceção e entrada fora do esperado.
