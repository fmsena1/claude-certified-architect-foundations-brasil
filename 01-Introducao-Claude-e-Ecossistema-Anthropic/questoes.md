# Revisão Guiada - Introdução à Claude e ao Ecossistema Anthropic

## Quick Review (Q&A)

- **Pergunta rápida:** Claude é um produto ou um modelo?
  **Resposta curta:** É a família de modelos; os produtos são construídos em cima dela.
- **Pergunta rápida:** Claude.ai e a API são a mesma coisa?
  **Resposta curta:** Não. Claude.ai é produto de consumo; a API é para integrar em sistemas próprios.
- **Pergunta rápida:** Claude Code é um chatbot genérico?
  **Resposta curta:** Não. É um agente voltado a tarefas de engenharia de software.
- **Pergunta rápida:** Bedrock muda a capacidade do modelo Claude?
  **Resposta curta:** Não. Muda o canal de distribuição, billing e compliance.
- **Pergunta rápida:** Por onde começar quando o requisito ainda não está claro?
  **Resposta curta:** Pelo produto pronto (Claude.ai), antes de integrar via API.
