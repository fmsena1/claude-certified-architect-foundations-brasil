# Flashcards - Introdução à Claude e ao Ecossistema Anthropic

## Card 01

**Pergunta:** O que é Claude?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
A família de modelos de linguagem da Anthropic. "Claude" designa o modelo, não um produto específico.

</details>

## Card 02

**Pergunta:** Qual a diferença entre Claude.ai e a Claude Developer Platform?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
Claude.ai é o produto de consumo para conversar direto; a Developer Platform (Console + API) é para integrar Claude em sistemas próprios.

</details>

## Card 03

**Pergunta:** O que é "usar Claude" versus "construir com Claude"?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
Usar é consumir um produto pronto (Claude.ai, integrações); construir é integrar via API/SDK com controle total do fluxo.

</details>

## Card 04

**Pergunta:** Claude Code serve para quê?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
É um agente de linha de comando/IDE voltado a tarefas de engenharia de software, não um chatbot genérico.

</details>

## Card 05

**Pergunta:** O que é o Claude Agent SDK?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
Um framework para construir agentes autônomos usando o mesmo loop de execução do Claude Code.

</details>

## Card 06

**Pergunta:** Bedrock, Vertex AI e Foundry mudam o modelo Claude?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
Não. São canais de distribuição do mesmo modelo; mudam billing, compliance e integração com a nuvem já usada, não a capacidade do modelo.

</details>

## Card 07

**Pergunta:** Por que validar em Claude.ai antes de integrar via API?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
Porque custa menos testar a ideia num produto pronto do que construir e depois refazer uma integração via API.

</details>

## Card 08

**Pergunta:** Quando um problema deixa de ser "chamada simples de API" e vira "agente"?

<details>
<summary><strong>Ver resposta</strong></summary>

**Resposta:**
Quando o sistema precisa decidir e agir sozinho usando ferramentas, não só responder a uma pergunta pontual.

</details>
