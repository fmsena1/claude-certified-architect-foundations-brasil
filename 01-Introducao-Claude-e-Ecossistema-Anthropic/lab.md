# Lab — Módulo 01: Introdução à Claude e ao Ecossistema Anthropic

## Mapa de decisão: produto pronto, API ou agente

Este micro-lab treina o raciocínio de escolha de canal antes de entrar nos módulos técnicos.

## Pré-requisitos

- Ter lido o README do módulo.
- Separar 20 minutos para classificar cenários.
- Opcional: uma conta gratuita em claude.ai para observar a interface.

## Passo a passo

1. Liste cinco necessidades reais do seu contexto: resumir texto, responder dúvida interna, automatizar uma tarefa repetitiva, revisar código, agir sozinho sobre um sistema.
2. Para cada necessidade, responda: isso é para uma pessoa usar manualmente, ou precisa estar dentro de um sistema?
3. Marque o canal mais adequado: Claude.ai, integração pronta (Slack/Microsoft 365), API/Developer Platform, Claude Code ou um agente com Claude Agent SDK.
4. Justifique cada escolha em uma frase, citando se o ponto decisivo foi volume, automação ou necessidade de ação autônoma.
5. Confronte suas respostas com o exemplo prático do README e ajuste o raciocínio onde necessário.

## O que observar

- Nem toda necessidade de IA generativa exige integração via API.
- O critério decisivo raramente é "qual modelo" — é "como isso vai ser consumido".
- Confundir produto de consumo com plataforma de integração é o erro mais comum neste estágio.

## Custos e limpeza

- Este lab não exige custo: é um exercício de classificação, não de chamada de API.
- Se você abrir uma conta na Developer Platform apenas para explorar a interface, não gere chaves de API que não vão ser usadas.
