# Revisão Guiada - Fundamentos de ML para LLMs

## Quick Review (Q&A)

- **Pergunta rápida:** O que acontece a cada chamada de API?
  **Resposta curta:** Inferência sobre um modelo já treinado, sem alterar seus pesos.
- **Pergunta rápida:** Qual é a opção mais barata de customização?
  **Resposta curta:** Prompting.
- **Pergunta rápida:** Quando usar RAG em vez de só prompting?
  **Resposta curta:** Quando o conhecimento externo é volumoso e muda com frequência.
- **Pergunta rápida:** Fine-tuning deveria ser a primeira opção?
  **Resposta curta:** Não. É a última, depois de esgotar prompting e RAG.
- **Pergunta rápida:** Como saber se um prompt generaliza?
  **Resposta curta:** Testando com variações do input, não só com o exemplo original.
