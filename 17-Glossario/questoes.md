# Revisão Guiada - Glossário

## Quick Review (Q&A)

- **Pergunta rápida:** O que é um embedding?
  **Resposta curta:** Uma representação vetorial de um texto, construída para que textos de significado semelhante fiquem próximos no espaço vetorial.
- **Pergunta rápida:** O que é um subagente?
  **Resposta curta:** Um agente especializado, com objetivo delimitado, invocado por um agente orquestrador para resolver uma parte específica de uma tarefa maior.
- **Pergunta rápida:** O que é a janela de contexto?
  **Resposta curta:** A quantidade máxima de tokens que o modelo processa numa única chamada, somando entrada e saída.
- **Pergunta rápida:** O que é um guardrail técnico?
  **Resposta curta:** Um controle implementado pela aplicação (filtro, validação, bloqueio) para reforçar uma política de uso, complementando o comportamento padrão do modelo.
- **Pergunta rápida:** O que é sumarização progressiva?
  **Resposta curta:** Uma técnica que substitui turnos antigos de uma conversa por um resumo compacto, preservando decisões e fatos relevantes em vez de descartar histórico sem critério.
