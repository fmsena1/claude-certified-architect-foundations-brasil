# Revisão Guiada - Agentes e Claude Agent SDK

## Quick Review (Q&A)

- **Pergunta rápida:** O que diferencia um agente autônomo de um assistente com ferramentas?
  **Resposta curta:** O agente decide sozinho quando a tarefa termina; o assistente age pontualmente dentro de uma troca.
- **Pergunta rápida:** Quais são as três etapas do loop de um agente?
  **Resposta curta:** Perceber, decidir e agir, em ciclo repetido.
- **Pergunta rápida:** O que acontece se um agente autônomo não tiver critério de parada?
  **Resposta curta:** Ele pode continuar iterando sem gerar valor adicional.
- **Pergunta rápida:** Para que serve um subagente?
  **Resposta curta:** Isolar contexto e responsabilidade de uma subtarefa dentro de um agente orquestrador.
- **Pergunta rápida:** Quando vale a pena orquestrar múltiplos agentes em vez de usar um único?
  **Resposta curta:** Quando há paralelismo real ou contextos muito distintos que justificam o custo de coordenação.
