# Cheatsheet — Módulo 18: Recursos e Links

> Revisão rápida de onde procurar cada tipo de informação oficial. Endereços específicos mudam com o tempo — confirme sempre em [links.md](./links.md).

## Visão rápida

| Tópico | O que lembrar | Cuidado/erro comum |
| --- | --- | --- |
| Documentação técnica | Fonte de verdade para API, modelos, limites e parâmetros | Não confundir com anúncio de produto |
| Anúncios de produto | Registra lançamento, mudança e descontinuação de modelo | Nem sempre traz detalhe técnico de implementação |
| Console da Anthropic | Acesso a chaves de API, billing e configuração de conta | Não é fonte de documentação conceitual |
| Repositórios open source oficiais | Código de referência, SDKs e exemplos mantidos pela Anthropic | Repositórios de terceiros não têm o mesmo peso de confiança |
| Model Context Protocol | Especificação aberta do padrão de integração de ferramentas | É um protocolo aberto, não exclusivo de um único fornecedor |
| Central de confiança (Trust) | Postura de segurança, privacidade e conformidade | Não substitui contrato jurídico específico da sua organização |

## Regras práticas

- Antes de decidir arquitetura com base em um número (preço, limite, nome de modelo), confirme na fonte oficial atual.
- Separe "como a API funciona" (documentação) de "o que foi lançado ou mudou" (anúncio).
- Use repositórios open source oficiais como referência de código, não como garantia de suporte total a cada caso de uso.
- Trate qualquer valor específico deste repositório como desatualizável — a fonte oficial sempre tem prioridade.

## Gatilhos de memorização

- Dúvida de "como funciona" -> documentação técnica.
- Dúvida de "o que mudou" -> anúncios/changelog.
- Dúvida de "isso é seguro/compliance" -> central de confiança.
- Dúvida de "como integrar ferramentas" -> especificação do protocolo aberto.
