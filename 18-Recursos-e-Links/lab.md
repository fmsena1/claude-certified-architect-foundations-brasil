# Lab — Módulo 18: Recursos e Links

## Monte sua lista pessoal de fontes para acompanhar o ecossistema Claude

Este micro-lab não exige chamada de API: o objetivo é sair do repositório com um hábito de acompanhamento, não apenas com uma leitura pontual.

## Pré-requisitos

- Ter revisado os módulos 16 (Simulados e Questões) e 17 (Glossário).
- Acesso à internet para abrir as páginas listadas em [links.md](./links.md).
- 20 a 30 minutos.

## Passo a passo

1. Abra a documentação técnica oficial (Claude Docs) e localize a página atual sobre a linha de modelos.
2. Abra os anúncios oficiais (Anthropic News) e identifique a mudança mais recente relevante para o seu contexto de trabalho.
3. Abra a lista de repositórios open source oficiais no GitHub e identifique um repositório relevante para a sua stack (SDK, exemplos, MCP).
4. Abra a especificação do Model Context Protocol e identifique, em alto nível, o que ela padroniza.
5. Monte uma lista pessoal curta (4 a 6 itens) com as páginas que você deveria revisitar periodicamente, priorizando as que mudam com mais frequência para o seu caso de uso.
6. Defina uma cadência de revisão realista (ex.: mensal, a cada início de projeto novo) para essa lista.

## O que observar

- A documentação técnica tende a mudar com mais frequência que a página institucional.
- Nem toda mudança relevante aparece nos dois lugares ao mesmo tempo — vale checar mais de uma fonte antes de uma decisão importante.
- Uma lista pessoal de fontes é mais útil do que tentar memorizar valores específicos que vão ficar desatualizados.

## Custos e limpeza

- Este lab não envolve chamadas de API pagas; é apenas navegação e curadoria.
- Não é necessário nenhum passo de limpeza.
